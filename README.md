# 삼목 10×10

10×10 판에서 흑과 백이 번갈아 돌을 놓아, 가로·세로·대각선으로 3개를 먼저 잇는 쪽이 이기는 두 사람용 게임입니다. `index.html` 한 파일이 전부입니다.

## 쓰는 법

`index.html`을 브라우저로 열거나 GitHub Pages로 배포해 엽니다. 인터넷 연결 없이도 동작합니다.

## 규칙

- 흑이 먼저 두고, 번갈아 빈 교차점에 돌을 놓습니다.
- 같은 색 돌을 가로·세로·대각선으로 3개 이상 이으면 이깁니다.
- 판이 가득 차도 승부가 나지 않으면 무승부입니다.

## 시험

```bash
npm test
```

Node 22 기본 시험 도구만 씁니다. 설치할 패키지가 없습니다.
