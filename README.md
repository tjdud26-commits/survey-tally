# survey-tally

엑셀에서 설문 응답을 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여주는 페이지입니다. `index.html` 한 파일이 전부입니다.

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산하고, 보내거나 저장하지 않습니다. CSP(`default-src 'none'`)로 외부 요청을 막습니다.

## 쓰는 법

`index.html`을 브라우저로 열거나 GitHub Pages로 배포해 엽니다. 엑셀에서 머리글 줄부터 응답까지 복사해 입력칸에 붙여넣으면 됩니다.

## 집계 규칙

- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`~`5`면 **유효**, 비었거나 공백만 있으면 **빈 응답**, 그 밖의 값은 **제외**입니다.
- 머리글보다 칸이 모자란 줄은 모자란 칸을 빈 응답으로 셉니다.
- **평균**은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 보여줍니다. 유효 응답이 없으면 `-`입니다.

세부 사항은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

Node 22 이상, 설치할 패키지는 없습니다.

```bash
npm test
```

계산 로직은 `index.html`의 `<script id="tally-core">` 블록에 있고, 시험은 이 블록을 그대로 꺼내 실행합니다.
