# 간단한 게임 모음

컴퓨터와 두거나 두 사람이 한 화면에서 번갈아 둘 수 있는 간단한 게임들입니다. 게임마다 HTML 파일 하나로 되어 있고, 외부 라이브러리·글꼴·네트워크·저장소를 쓰지 않습니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 목록 (첫 화면) |
| `mancala.html` | 만칼라 |
| `samok.html` | 삼목 10×10 |

브라우저로 `index.html`을 열거나 GitHub Pages로 배포해 엽니다. 인터넷 연결 없이도 동작합니다.

## 만칼라

- 구덩이 6개씩, 처음엔 구덩이마다 씨앗 4개. 각자 오른쪽에 창고가 있습니다(아래쪽 사람 기준).
- 내 구덩이 하나의 씨앗을 모두 집어 시계 반대 방향으로 한 칸에 하나씩 뿌립니다. 상대 창고는 건너뜁니다.
- 마지막 씨앗이 내 창고에 들어가면 한 번 더 둡니다.
- 마지막 씨앗이 내 쪽의 빈 구덩이에 떨어지고 맞은편 구덩이에 씨앗이 있으면, 둘 다 따서 내 창고에 넣습니다.
- 어느 한쪽 구덩이가 모두 비면 끝납니다. 남은 씨앗은 각자 자기 창고로 가고, 창고에 씨앗이 많은 쪽이 이깁니다.
- 컴퓨터와 둘 때 나는 아래 줄이고, 먼저·나중과 난이도를 고릅니다.
  - **쉬움**: 열 번에 네 번쯤은 아무 수나 두고, 나머지는 바로 다음 결과만 봅니다.
  - **보통**: 4수 앞까지 내다봅니다.
  - **어려움**: 9수 앞까지 내다봅니다.

## 삼목 10×10

- 흑이 먼저 두고 번갈아 둡니다. 같은 색 돌을 가로·세로·대각선으로 3개 이상 이으면 이깁니다. 판이 가득 차면 무승부입니다.
- 컴퓨터와 둘 때 내 색(흑·백)과 난이도를 고릅니다.
  - **쉬움**: 이길 수 있으면 이기고, 상대가 이길 자리는 막고, 나머지는 돌 근처에 무작위로 둡니다.
  - **어려움**: 쉬움에 더해, 이길 자리를 두 곳 동시에 만드는 수를 두고, 상대가 그런 수를 둘 자리를 미리 막습니다.
- 3개 잇기는 흑(먼저 두는 쪽)이 제대로 두면 항상 이기는 게임입니다. 어려움 컴퓨터가 흑이면 이기기 어렵습니다.

## 구조

각 게임 페이지는 규칙·컴퓨터 계산을 담은 스크립트(`samok.html`의 `game-core`, `mancala.html`의 `mancala-core`)와 화면 스크립트를 나눕니다. 계산 스크립트는 화면(DOM)을 쓰지 않습니다.

## 시험

```bash
npm test
```

Node 22 기본 시험 도구만 씁니다. 설치할 패키지가 없습니다. 시험은 각 페이지의 계산 스크립트를 그대로 꺼내 실행합니다.
