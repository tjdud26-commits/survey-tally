# 삼목 10×10

10×10 판에서 흑과 백이 번갈아 돌을 놓아, 가로·세로·대각선으로 3개를 먼저 잇는 쪽이 이기는 게임입니다. 컴퓨터와 두거나 두 사람이 한 화면에서 둘 수 있습니다. `index.html` 한 파일이 전부입니다.

## 쓰는 법

`index.html`을 브라우저로 열거나 GitHub Pages로 배포해 엽니다. 인터넷 연결 없이도 동작합니다.

## 규칙

- 흑이 먼저 두고, 번갈아 빈 교차점에 돌을 놓습니다.
- 같은 색 돌을 가로·세로·대각선으로 3개 이상 이으면 이깁니다.
- 판이 가득 차도 승부가 나지 않으면 무승부입니다.

## 컴퓨터 상대

- 내 색(흑·백)과 난이도를 고릅니다. 백을 고르면 컴퓨터가 먼저 둡니다.
- **쉬움**: 이길 수 있으면 이기고, 상대가 이길 자리는 막고, 나머지는 돌 근처에 무작위로 둡니다.
- **어려움**: 쉬움에 더해, 이길 자리를 두 곳 동시에 만드는 수를 두고, 상대가 그런 수를 둘 자리를 미리 막습니다.
- 3개 잇기는 흑(먼저 두는 쪽)이 제대로 두면 항상 이기는 게임입니다. 어려움 컴퓨터가 흑이면 이기기 어렵습니다.
