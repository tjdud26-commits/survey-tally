# 설문 집계기 계획서

## 목표

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여주는 단일 파일 `index.html`.

## 제약

- 파일 하나(`index.html`). 외부 라이브러리·외부 글꼴·분석 도구 없음.
- 붙여넣은 데이터는 브라우저 밖으로 보내지 않고 저장하지 않는다.
  - 네트워크 요청 코드(`fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket`)와 저장소(`localStorage`, `sessionStorage`, `indexedDB`, 쿠키)를 쓰지 않는다.
  - Content-Security-Policy로 `default-src 'none'`을 걸어 실수로 넣은 외부 요청도 브라우저가 막게 한다.
  - 입력칸에 `spellcheck="false"`, `autocomplete="off"`를 둔다. 브라우저의 온라인 맞춤법 검사로 내용이 나가지 않게 하기 위함이다.
  - `<form>` 제출을 쓰지 않는다.
- 저장소 맨 위에 빈 `.nojekyll`.

## 집계 규칙

| 항목 | 규칙 |
|---|---|
| 첫 줄 | 머리글. 둘째 열부터가 문항 이름 |
| 첫 열 | 응답번호. 집계하지 않음 |
| 유효 | 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나 |
| 빈 응답 | 비었거나 공백만 있음 (줄바꿈 없는 공백 U+00A0, 전각 공백 U+3000 포함) |
| 제외 | 그 밖의 값 (`6`, `0`, `3.5`, `5.0`, `５`, `예` 등) |
| 평균 | 유효 합 ÷ 유효 수, 소수 셋째 자리에서 반올림해 둘째 자리까지 (`3.00` 형식). 유효 0이면 `-` |
| 짧은 줄 | 머리글보다 칸이 모자라면 모자란 칸을 빈 응답으로 셈 |

계획서에서 정한 세부 사항(요구에 없던 부분):

- **평균 반올림은 정수 계산으로 한다.** 부동소수 오차(예: 1.005 → 1.00) 없이 정확히 반올림하려고, `floor((합×200 + 수) ÷ (2×수))`로 백분의 일 단위 정수를 구한 뒤 표시한다. 값이 모두 양수라 "반올림 = 0.5 올림"이다.
- **줄 구분**은 `\r\n`, `\n`, `\r`을 모두 받는다.
- **완전히 빈 줄**(길이 0)은 응답으로 세지 않는다. 엑셀 복사 끝에 붙는 줄바꿈이나 실수로 들어간 빈 줄 때문에 모든 문항의 빈 응답이 늘어나는 것을 막기 위함이다. 탭만 있는 줄(`\t\t\t`)은 엑셀에서 빈 행을 복사한 것이므로 응답으로 세어 모든 칸이 빈 응답이 된다.
- **머리글보다 칸이 많은 줄**은 넘치는 칸을 무시한다.
- **따옴표 칸**: 엑셀은 칸 안에 줄바꿈·탭·따옴표가 있으면 `"..."`로 감싸고 안의 `"`를 `""`로 복사한다. 이 형식을 풀어서 읽는다. 그러지 않으면 의견 칸 안의 줄바꿈 때문에 줄이 쪼개져 집계가 틀어진다.
- **머리글 이름이 빈 문항**은 `(열 N)`으로 표시한다.
- 머리글만 있고 응답이 없으면 각 문항의 유효 0, 평균 `-`.
- 문항이 없는 경우(머리글이 한 칸뿐)나 입력이 비었으면 표 대신 안내 문구를 보여준다.

## 구조

`index.html` 안에서 계산과 화면을 나눈다.

- `<script id="tally-core">`: 순수 계산만. DOM을 건드리지 않음. `TallyCore` 객체로 `parseTsv`, `classifyCell`, `formatAverage`, `tally`를 내보낸다.
- `<script id="tally-ui">`: 입력칸 읽기, `TallyCore.tally` 호출, 표 그리기. 붙여넣거나 고칠 때마다 다시 계산.
- 결과 표의 문항 이름은 `textContent`로 넣어 붙여넣은 내용이 HTML로 해석되지 않게 한다.

## 시험

Node 기본 시험 도구(`node --test`)만 쓴다. 설치할 패키지 없음.

- `tests/core.test.js`: `index.html`에서 `tally-core` 스크립트를 꺼내 `vm`으로 실행하고 규칙별로 시험한다. 화면에 실제로 쓰이는 코드 그대로를 시험하게 된다.
- `tests/policy.test.js`: `index.html`에 외부 주소 로딩, 네트워크 API, 저장소 API, `<form>`이 없는지, CSP가 있는지, `.nojekyll`이 비어 있는지 확인한다.
- GitHub Actions에서 같은 시험을 돌린다.
- 화면은 로컬에서 브라우저로 직접 확인한다(저장소에 넣지 않음).
